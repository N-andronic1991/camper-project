# 🚐 CamperTruck App

CamperTruck is a modern web application for renting or buying trucks and
campervans. Built with React, Redux Toolkit, and React Router, it provides users
with a smooth experience to explore vehicle details, check reviews, and make
informed decisions.

## Tech Stack

- **React** – Frontend framework
- **Redux Toolkit** – State management
- **React Router DOM** – Routing
- **Vite** – Lightning-fast build tool
- **CSS modules** – Styling tool
- **Axios** – For handling backend communication
- **React Hook Form Yup & @hookform/resolvers**

## Features

- Browse available campervans and trucks
- View detailed information for each vehicle
- Read user reviews
- Filter and sort by features or availability
- Navigation with React Router
- Fast and optimized with Vite

## Getting Started

1.  Clone the repository: git clone
    https://github.com/N-andronic1991/camper-project.git
2.  Install dependencies: npm install

3.  Run the development server: npm run dev. The app will be running at
    http://localhost:5173/
